# Architecture and wireframes

The architecture separates the SmartSearch search/recommendation layer from
Vietnam Airlines' booking, PSS/GDS and payment systems. The solid path shows
the current Round 2 prototype. The dashed path is a future VNA-authorised data
integration and is not claimed as implemented.

Position it consistently in the pitch: SmartSearch does not replace NEO; it
extends VNA's direct-channel capability to complex discovery and, after VNA
authorisation, external AI-assistant channels.

- `architecture.svg` — current demo, future integration and out-of-scope boundary.
- `wireframe_before_after.svg` — Australian web search before and after SmartSearch.

Use both figures in the Round 2 pitch deck and keep the out-of-scope label
visible when explaining the handoff.
